# Weekly Lead Review (Aapka Sarathi)

## Schedule
- Run every Monday morning for previous Monday-Sunday period.

## Inputs
- Formspree submissions dashboard (`mlgwzvoj`).
- Call/WhatsApp follow-up notes.
- Booking confirmations.

## Steps
1. Count total leads received in the week.
2. Count leads contacted within 15 minutes.
3. Count leads contacted same day.
4. Mark qualified leads (clear destination + date + budget intent).
5. Mark booked leads.
6. Calculate booking rate: `booked / total * 100`.
7. Note most common source page (`/`, `/contact.html`, etc.).
8. Add blockers and next actions.

## KPI Targets
- First response within 15 minutes: >= 60%.
- Same-day response: >= 95%.
- Weekly booking rate: >= 12% (adjust after 4 weeks baseline).

## Action Rules
- If 15-minute response is below target: assign a dedicated on-call lead owner.
- If booking rate drops for 2 weeks: revise package copy and call scripts.
- If most leads come from one page: prioritize that page for CTA and content updates.

## Logging
- Copy `lead-review-template.csv` each week and store in `/operations/reports/`.
